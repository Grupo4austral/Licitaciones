Por qué LicitIA
01
Perfil de empresa simple
Cargá rubro, zona y palabras clave. El sistema usa ese perfil para buscar oportunidades relevantes.
02
Licitaciones nacionales
El backend consume datos públicos de Datos Argentina y COMPR.AR para mostrar oportunidades disponibles.
03
Alertas en tiempo real
Con WebSocket, el frontend recibe una notificación cuando aparece una licitación compatible con el perfil.
